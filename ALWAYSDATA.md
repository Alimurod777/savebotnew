# Alwaysdata service (Wzgram)

Wzgram uses `venv/` and `start_alwaysdata.sh`. Follow
[the Wzgram deployment guide](ALWAYSData.md) for installation and panel settings.
`start-service.sh` is an alias for the same launcher; both use the Wzgram folder.
Keep the existing `.env` unchanged when updating the code.
