# Oddiy bosh sahifa

`index.html` — tashqi kutubxonasiz statik HTML/CSS sahifa. JavaScript, bot yoki fon jarayoni yo‘q.

## Alwaysdata

1. `index.html` faylini `/home/small/www/index.html` ga joylang.
2. Web → Sites bo‘limida sayt ildiz papkasini `/home/small/www` qilib belgilang.
3. Sayt manzilini brauzerda oching. SSH ulanishini ochiq qoldirish shart emas.

Botlar bu sahifa orqali ishga tushirilmaydi. Uzluksiz bot uchun pullik tarifdagi Advanced → Services funksiyasidan foydalaning va hisob resurs limitlariga rioya qiling. Sahifa mavjudligi boshqa jarayonlar uchun ruxsat bermaydi.

Rasmiy hujjat: https://help.alwaysdata.com/en/docs/web-hosting/services/
